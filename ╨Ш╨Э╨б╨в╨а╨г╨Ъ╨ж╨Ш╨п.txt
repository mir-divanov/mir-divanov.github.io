САЙТ «МИР ДИВАНОВ» — ИНСТРУКЦИЯ
================================

ЧТО В ПАПКЕ
-----------
index.html      главная страница: все тексты, каталог из 52 моделей, контакты
css/style.css   оформление: цвета, шрифты, сетка, вид на телефоне и планшете
js/main.js      меню, фильтры и поиск в каталоге, окно с описанием модели
photos/         фото диванов в полном размере (53 файла)
thumbs/         уменьшенные фото для карточек (53 файла)
favicon.svg     значок сайта во вкладке браузера
og.jpg          картинка, которая показывается при отправке ссылки в мессенджере
robots.txt      файл для поисковых систем
ИНСТРУКЦИЯ.txt  этот файл (на сайт его загружать не нужно)


1. КАК ПОСМОТРЕТЬ САЙТ НА КОМПЬЮТЕРЕ
------------------------------------
Распакуйте архив и дважды щёлкните по файлу index.html.
Сайт откроется в браузере. Ничего устанавливать не нужно.


2. КАК БЕСПЛАТНО ВЫЛОЖИТЬ САЙТ НА GITHUB PAGES
----------------------------------------------
Понадобятся: компьютер, браузер, электронная почта. Всё делается
в браузере, программы ставить не нужно. Сайт GitHub на английском,
ниже названия кнопок даны так, как они написаны на экране.

Шаг 1. Регистрация
  1) Откройте https://github.com и нажмите Sign up.
  2) Введите почту, придумайте пароль и имя пользователя (Username).
     ВАЖНО: имя пользователя станет адресом сайта.
     Например, имя mir-divanov даст адрес https://mir-divanov.github.io
     Можно только латинские буквы, цифры и дефис.
  3) Подтвердите почту: введите код из письма от GitHub.

Шаг 2. Создание хранилища для сайта (репозитория)
  1) В правом верхнем углу нажмите «+» и выберите New repository.
  2) В поле Repository name впишите: ВАШЕ-ИМЯ.github.io
     Пример: если имя пользователя mir-divanov,
     то название должно быть mir-divanov.github.io
     Название должно точно совпадать с именем пользователя.
  3) Ниже выберите Public (на бесплатном тарифе сайт работает
     только в открытом репозитории).
  4) Включите галочку Add a README file.
  5) Нажмите зелёную кнопку Create repository.

Шаг 3. Загрузка файлов, первая часть
  GitHub принимает не больше 100 файлов за один раз, а на сайте их 112,
  поэтому загружаем в два приёма.
  1) На странице репозитория нажмите Add file, затем Upload files.
  2) Откройте на компьютере папку mir-divanov-site.
  3) Выделите и перетащите в окно браузера:
       index.html
       favicon.svg
       og.jpg
       robots.txt
       папку css
       папку js
       папку thumbs
     Папку photos пока НЕ перетаскивайте.
     Перетаскивать нужно сами файлы и папки, а не папку
     mir-divanov-site целиком.
  4) Дождитесь, пока все файлы появятся в списке под окном загрузки.
  5) Внизу нажмите зелёную кнопку Commit changes.

Шаг 4. Загрузка файлов, вторая часть
  1) Снова нажмите Add file, затем Upload files.
  2) Перетащите в окно папку photos.
  3) Дождитесь окончания загрузки и нажмите Commit changes.

  Проверка: на главной странице репозитория должны быть видны
  папки css, js, photos, thumbs и файлы index.html, favicon.svg,
  og.jpg, robots.txt, README.md. Файл index.html должен лежать
  в самом верху, а не внутри другой папки.

Шаг 5. Включение сайта
  1) Вверху страницы репозитория нажмите Settings.
  2) В меню слева, в разделе Code and automation, нажмите Pages.
  3) В блоке Build and deployment в поле Source выберите
     Deploy from a branch.
  4) В поле Branch вместо None выберите main, рядом оставьте
     / (root) и нажмите Save.

Шаг 6. Проверка
  Подождите до 10 минут и откройте в браузере адрес
  https://ВАШЕ-ИМЯ.github.io
  Тот же адрес появится вверху страницы Settings, Pages
  с надписью «Your site is live at...».

Если сайт не открылся
  - Ошибка 404: подождите ещё несколько минут и обновите страницу.
    Проверьте, что index.html лежит в самом верху репозитория
    и что в Settings, Pages выбрана ветка main.
  - Сайт открылся без оформления или без фото: не загрузилась одна
    из папок (css, js, thumbs, photos). Загрузите её ещё раз.
  - Название репозитория не совпадает с именем пользователя: тогда
    сайт откроется по адресу https://ВАШЕ-ИМЯ.github.io/НАЗВАНИЕ/


3. КАК ИЗМЕНИТЬ САЙТ ПОСЛЕ ПУБЛИКАЦИИ
-------------------------------------
Способ 1. Прямо на GitHub
  1) Откройте в репозитории файл index.html.
  2) Нажмите значок карандаша (Edit this file) справа над текстом.
  3) Нажмите Ctrl+F и найдите нужное место, исправьте текст.
  4) Нажмите Commit changes. Сайт обновится за несколько минут.

Способ 2. Заменить файл
  Исправьте index.html на компьютере в Блокноте и загрузите его
  через Add file, Upload files. Файл с тем же названием заменит старый.

Как поменять цену
  Найдите модель по названию (например: Каштан).
  Цена записана у модели в двух местах, поменяйте оба:
    data-price="35000"
    <p class="price">35 000 ₽</p>

Телефон, адреса и остальные тексты меняются так же: поиском
по старому значению.


4. ПОСЛЕ ПУБЛИКАЦИИ
-------------------
  1) В начале index.html есть три строки с example.ru, закрытые
     значками <!-- и -->. Уберите эти значки и впишите адрес сайта
     вместо example.ru. Тогда при отправке ссылки в мессенджере
     будет показываться картинка с диваном.
  2) Файл robots.txt можно оставить как есть.
  3) Добавьте сайт в Яндекс Вебмастер (webmaster.yandex.ru) и
     Google Search Console, чтобы он быстрее появился в поиске.
  4) Укажите адрес сайта в карточках магазина в 2ГИС и Яндекс Картах.


5. ЕСЛИ ПОЗЖЕ ЗАХОТИТЕ СВОЙ АДРЕС
---------------------------------
Адрес вида mir-divanov.ru покупается у регистратора доменов
(например, REG.RU, Beget, Timeweb) и подключается к этому же
сайту в Settings, Pages, поле Custom domain. Сайт при этом
остаётся на GitHub бесплатно, платить нужно только за домен.
